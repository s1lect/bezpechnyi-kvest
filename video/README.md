# Промовідео «Безпечний квест»

40-секундне відео 1920×1080 на [Remotion](https://www.remotion.dev/). Ілюстрації та шрифти — ті самі, що на сайті.

```bash
npm install
npm run dev          # Remotion Studio
npm run soundtrack   # згенерувати саундтрек (Python 3 + numpy)
npm run render       # → ../public/promo.mp4
npm run poster       # → ../public/promo-poster.jpg
```

Сцени (`src/scenes/`): заставка, гасло, карта міста, пошук небезпек, фішинг-чат, класний режим, переваги, фінал.
Саундтрек синтезовано кодом (`scripts/soundtrack.py`), тому сторонніх семплів і проблем з ліцензіями немає.

Ліцензія Remotion: безкоштовна для команд до 3 осіб, див. [remotion.dev/license](https://www.remotion.dev/docs/license).
