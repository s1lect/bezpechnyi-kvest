# Дорожня карта

Повна концепція на 100 пунктів, план пілотування і подання на експертизу — у документі
[«Безпечний квест» — план](https://claude.ai/artifact/W7koyhQwxAmDJyjZaoYMnR). Тут — стан реалізації.

## Етап 1. Пілотна версія (MVP) — зроблено

- [x] Ілюстрована карта міста з шістьма районами-темами
- [x] Рушій квестів: 9 типів кроків, бали з першої спроби, екран результату
- [x] 7 квестів: пожежа, повітряна тривога, мінна безпека, фішинг, шахрайський дзвінок, булінг, СЛР
- [x] Озвучення українською (Web Speech API) з підтримкою записаних аудіофайлів
- [x] Класний режим для проєктора з підрахунком голосів і QR-код для телефонів
- [x] Конспекти уроків на 45 хв і таблиця відповідності програмі НУШ
- [x] Спокійний режим, великий текст, керування з клавіатури, відповідність базовим вимогам доступності
- [x] Кнопка «Потрібна допомога» з екстреними службами й гарячими лініями
- [x] Значки, сертифікат для друку, прогрес лише на пристрої
- [x] Офлайн-режим (PWA) і розділ для батьків

## Етап 2. Пілот у школах

- [ ] Рецензування кожного квесту фахівцями (ДСНС, МОЗ, психолог, НБУ, кіберполіція)
- [ ] Звірка очікуваних результатів із кодами Державного стандарту (методист)
- [ ] Пілот у 3–5 школах, пре-/посттести, відгуки вчителів
- [ ] Професійне озвучення ключових реплік акторами
- [ ] Версії з субтитрами українською жестовою мовою для ключових відео

## Етап 3. Розширення змісту

- [ ] Дорожній рух, вода й лід, газ, електрика, незнайомець (район «Дім і вулиця»)
- [ ] Блекаут, сімейний план, вербування в месенджерах (район «Воєнний час»)
- [ ] Приватність у соцмережах, діпфейки, грумінг, ШІ (район «Інтернет»)
- [ ] Дропери, онлайн-покупки, перший бюджет (район «Гроші»)
- [ ] Конфлікт і медіація, особисті межі, дискримінація (район «Стосунки»)
- [ ] Кровотеча, алергія, дихальні вправи, шкідливі звички (район «Здоров'я»)
- [ ] Вікові версії квестів для 1–4 і 10–11 класів

- [ ] CMS для методистів
