# Як додати квест

Квест — це звичайний TypeScript-об'єкт. Рушій сам намалює сцени, озвучить репліки, порахує бали й створить сторінку конспекту для
вчителя. Програмувати не потрібно: достатньо скопіювати наявний квест і змінити тексти.

## 1. Створіть файл

`src/data/quests/my-quest.ts`:

```ts
import type { Quest } from '../../types';

export const myQuest: Quest = {
  id: 'my-quest',                 // латиницею, стане адресою: #/quest/my-quest
  world: 'cyber',                 // home | war | cyber | money | people | health
  title: 'Назва квесту',
  tagline: 'Одне речення, що зачіпає: ситуація, з якої починається історія.',
  grades: '5–9',
  minutes: 15,
  curriculum: "«Здоров'я, безпека та добробут»: безпека в цифровому середовищі",
  outcomes: ['Очікуваний результат 1', 'Очікуваний результат 2'],
  reviewBy: 'Хто має перевірити зміст (ДСНС, психолог, лікар…)',
  lesson: {
    goal: 'Що учні вмітимуть після уроку.',
    stages: [{ minutes: 5, title: 'Вхід у тему', text: 'Що робить вчитель.' }],
    discussion: ['Питання для обговорення'],
    homework: 'Завдання, бажано разом із родиною.',
  },
  steps: [
    /* кроки — див. нижче */
  ],
};
```

## 2. Зареєструйте квест

Додайте його в `src/data/quests/index.ts`:

```ts
import { myQuest } from './my-quest';
export const QUESTS: Quest[] = [/* … */, myQuest];
```

## 3. Типи кроків

Кожен крок має унікальний `id`. Необов'язкові поля для всіх: `scene` (фон), `speaker` (хто говорить), `audio` (шлях до записаного
аудіо замість синтезу мовлення).

**Сцени:** `classroom`, `corridor`, `home`, `kitchen`, `street`, `field`, `phone`, `shelter`, `park`.

**Персонажі:** `narrator`, `olya` (рятувальниця), `kit` (Кібер-Кіт), `sova` (Сова Гривня), `taras` (однокласник), `mama`,
`stranger` (невідомий у телефоні), `student`.

### Репліка

```ts
{ id: 'intro', kind: 'line', scene: 'home', speaker: 'olya', text: 'Текст репліки.' }
```

### Вибір

Порядок варіантів перемішується автоматично. Пояснення пишіть так, щоб учень зрозумів, *чому*, — без докорів.

```ts
{
  id: 'q1', kind: 'choice', scene: 'street', speaker: 'narrator',
  text: 'Ситуація й питання?',
  options: [
    { text: 'Правильна дія', correct: true, feedback: 'Чому це правильно.' },
    { text: 'Типова помилка', correct: false, feedback: 'Чим вона небезпечна і що робити натомість.' },
  ],
}
```

### Знайди небезпеку

Працює на сценах `kitchen` і `field`. Координати `x`, `y`, `r` — у відсотках від ширини (x, r) і висоти (y) ілюстрації 1000×600.

```ts
{
  id: 'spot', kind: 'spot', scene: 'kitchen', speaker: 'olya',
  text: 'Знайди 5 небезпек.',
  hotspots: [{ id: 'pan', x: 21, y: 44, r: 7, label: 'Сковорідка без нагляду', explain: 'Пояснення.' }],
}
```

### Сортування

```ts
{
  id: 'sort', kind: 'sort', speaker: 'sova', text: 'Розклади.',
  buckets: ['Можна', 'Не можна'],
  items: [{ text: 'Ситуація', bucket: 1, explain: 'Пояснення.' }],
}
```

### Тривожна валіза

Учень обирає речі в межах `capacity` (кг). Перевірка пройдена, якщо є всі `essential: true` і вага не перевищена.

```ts
{
  id: 'pack', kind: 'pack', speaker: 'olya', text: 'Збери валізу.', capacity: 10,
  items: [{ name: 'Вода, 1 л', weight: 2, essential: true, note: 'Пояснення.' }],
}
```

### Підозрілий чат

`fragment` має точно збігатися з частиною тексту повідомлення.

```ts
{
  id: 'chat', kind: 'chat', speaker: 'kit', text: 'Знайди 2 підозрілі місця.',
  contact: 'Максим', contactNote: 'Однокласник',
  messages: [
    { from: 'them', text: 'Перешли мені код із СМС', flags: [{ fragment: 'код із СМС', explain: 'Пояснення.' }] },
  ],
}
```

### Ритм, пароль, правила

```ts
{ id: 'cpr', kind: 'rhythm', text: 'Натискай у темпі.', beats: 16, min: 100, max: 120 }
{ id: 'pw', kind: 'password', text: 'Придумай пароль-фразу.' }
{ id: 'rule', kind: 'rule', speaker: 'olya', title: 'Запам’ятай', points: ['Правило 1', 'Правило 2'] }
```

Останнім кроком квесту завжди має бути `rule` — короткий підсумок, який учень може переписати в зошит.

## Вимоги до змісту

1. **Травмочутливість.** Жодних описів поранень, загибелі, вибухів. Небезпеку показуємо через дії, а не через наслідки.
2. **Помилка — не провина.** Неправильна відповідь пояснюється спокійно й конкретно.
3. **Тільки перевірені правила.** Посилайтеся на офіційні рекомендації (ДСНС, МОЗ, НБУ, кіберполіція). Зазначте рецензента в
   `reviewBy`.
4. **Мова.** Коротко, на «ти», без канцеляриту. Одне речення — одна думка.
5. **Номери телефонів** беріть лише з `src/data/hotlines.ts`, щоб оновлювати їх в одному місці.
