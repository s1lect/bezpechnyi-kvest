# Участь у проєкті

Дякуємо, що хочете допомогти зробити школи безпечнішими.

## Чим можна допомогти

- **Вчителям і методистам** — запропонувати новий квест, виправити формулювання, поділитися досвідом уроку. Створіть
  [issue](https://github.com/s1lect/bezpechnyi-kvest/issues) з описом.
- **Фахівцям** (ДСНС, медицина, психологія, фінанси, кібербезпека) — перевірити зміст квесту своєї галузі.
- **Розробникам і дизайнерам** — код, ілюстрації, доступність.

## Як надіслати зміни

1. Зробіть fork і створіть гілку: `git checkout -b feature/nazva`.
2. Встановіть залежності `npm install` і запустіть `npm run dev`.
3. Новий квест додавайте за інструкцією [docs/CONTENT_GUIDE.md](docs/CONTENT_GUIDE.md).
4. Перед комітом перевірте: `npm run format`, `npm run lint`, `npm test` і `npm run build`.
5. Відкрийте pull request і коротко опишіть, що змінилося і навіщо.

## Правила змісту

Зміст для дітей має бути травмочутливим, перевіреним і без реклами. Деталі — у розділі «Вимоги до змісту» в
[CONTENT_GUIDE.md](docs/CONTENT_GUIDE.md).
